Per-user wallets (no approval) + USDT withdrawal flow

Every Telegram user who /starts the bot now gets their OWN fresh BSC
trading wallet instantly — no admin approval. The shared club wallet is
gone: balances, positions, orders, approvals, deposit notifications and
redeems are fully isolated per member.

- PredictFunApi/PredictSigner are now constructible per private key
  (constructor opts); a runtime manager caches one pair per user
- users/accounts.ts: per-user wallets in data/accounts.json, private keys
  AES-256-GCM encrypted (WALLET_MASTER_KEY env, falls back to a key
  derived from the bot token); sendUsdt for withdrawals
- /start: new members get a welcome card with their own address + funding
  steps; existing members get the round card with THEIR balance
- Withdrawal: 🏦 Wallet → 💸 Withdraw button → paste address → amount or
  "all" → inline Confirm & Send → "✅ Sent Done!" + BSCScan TX link
- /export now returns the member's own key (same inline confirm + 90s
  auto-delete); /approve removed; /users and /kick stay admin-only
- Deposit watcher, live settle/auto-redeem loop and fill reconciliation
  iterate over every member's wallet; settlement attribution is per-user
  (settledKeys now keyed per user)
- Startup approvals/announcements for the legacy env wallet removed
- README + .env.example updated
