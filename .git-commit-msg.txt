Multi-user club mode (max 10 members) + per-user limits & stats

- New users/registry: data/users.json registry seeded from
  TELEGRAM_ALLOWED_USERS (admins); strangers /start → access request →
  admin approves via /approve <id>; MAX_USERS caps members (default 10)
- Admin commands: /users (list + pending), /approve <id>, /kick <id>;
  access requests ping admins with an approve hint
- Per-member daily loss cap (USER_DAILY_LOSS_LIMIT_USDT, falls back to the
  global limit) checked on every bet; PnL attributed to the placing member
  via risk.recordSettlement → registry.recordPnl
- /stats shows the member's own line; /history filters to the member's
  trades (admins see all)
- /export restricted to admins (shared club wallet)
- Deposit watcher + startup announcements now target all approved members
- README + .env.example document the mode
